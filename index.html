01

Largest of Two Numbers

This Python program compares two numbers and displays the largest number.

Python
a = int(input("Enter First Number: "))
b = int(input("Enter Second Number: "))

if a > b:
    print("Largest =", a)
else:
    print("Largest =", b)
02

Assign Grades Based on Marks

This program assigns grades based on the marks entered by the student.

Python
marks = int(input("Enter Marks: "))

if marks >= 90:
    print("Grade A")
elif marks >= 80:
    print("Grade B")
elif marks >= 70:
    print("Grade C")
elif marks >= 60:
    print("Grade D")
else:
    print("Fail")
03

Leap Year

This program checks whether a given year is a leap year or not.

Python
year = int(input("Enter Year: "))

if year % 4 == 0:
    print("Leap Year")
else:
    print("Not Leap Year")
04

Electricity Bill Using Slab Rates

This program calculates the electricity bill based on the number of units consumed.

Python
units = int(input("Enter Units: "))

if units <= 100:
    bill = units * 1.5
elif units <= 200:
    bill = (100 * 1.5) + (units - 100) * 2.5
else:
    bill = (100 * 1.5) + (100 * 2.5) + (units - 200) * 4

print("Electricity Bill =", bill)
